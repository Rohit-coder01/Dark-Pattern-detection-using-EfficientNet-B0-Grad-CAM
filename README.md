# 🕵️‍♂️ Dark Pattern Detection in Web/Mobile UI

🚀 **Tech Stack:** Python | PyTorch | EfficientNet-B0 | Grad-CAM  
📊 **Task:** Detect and highlight dark patterns in web/mobile UI screenshots  
🎯 **Goal:** Lightweight, explainable, and efficient AI-based UI analysis system  

---

## 📌 Overview

This project focuses on detecting **dark patterns in web and mobile UI screenshots** using a lightweight deep learning approach. It replaces heavy models with an efficient architecture while maintaining strong performance and interpretability.

The system not only classifies dark patterns but also explains predictions using visual heatmaps.

---

## ⚙️ Features

- 🧠 **Lightweight Model:** EfficientNet-B0 for fast and efficient inference  
- 🎯 **Classification:** Detects multiple types of dark patterns in UI screenshots  
- 🔥 **Explainable AI:** Grad-CAM used to highlight suspicious regions in images  
- 📊 **High Performance:** Achieves ~80% accuracy with compact architecture  
- ⚖️ **Balanced Learning:** Handles class imbalance using weighted sampling & loss functions  
- 🖼️ **Visual Output:** Generates heatmaps and binary masks for interpretation  

---

## 🧪 Methodology

- 🔄 **Transfer Learning:** EfficientNet-B0 pretrained model fine-tuned for UI classification  
- ⚖️ **Class Imbalance Handling:** Weighted random sampling + class-weighted loss  
- 🔍 **Explainability:** Grad-CAM applied to visualize decision regions  
- ⚡ **Optimization:** Reduced model size while maintaining accuracy  

---

## 📊 Results

- ✅ Accuracy: ~80%  
- 📦 Model: Lightweight EfficientNet-B0  
- ⚡ Faster inference compared to heavy multimodal models  
- 🔍 Improved interpretability using Grad-CAM visualizations
